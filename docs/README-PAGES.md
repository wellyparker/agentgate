# GitHub Pages note

This folder is the GitHub Pages web root (Pages source: `/docs` on `main`).
`index.html`, `app.js`, `config.js`, `styles.css` here are a **deployment copy**
of `../frontend/` — edit the source in `frontend/` and re-copy after changes:

```
cp frontend/index.html frontend/app.js frontend/config.js frontend/styles.css docs/
```

`verification.md` in this folder is documentation only (not part of the site).
